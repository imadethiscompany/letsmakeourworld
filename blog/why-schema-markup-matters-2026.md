## 🔎 What Is Schema Markup?

Schema.org provides a vocabulary of **structured data** that tells search engines **exactly what your page is about** – product, article, FAQ, event, review, etc. When implemented correctly, Google can:

1. Generate **rich results** (stars, pricing, availability).
2. Populate **voice‑search answers**.
3. Feed **AI chat agents** with accurate facts.

## 📋 Essential Schemas for Every Site

| Schema Type | When to Use | Key Properties |
|-------------|------------|----------------|
| **Article** | Blog posts, news | `headline`, `author`, `datePublished`, `image` |
| **Product** | E‑commerce pages | `name`, `offers.price`, `offers.availability`, `review.rating` |
| **FAQ** | Help centers, landing pages | `question`, `answer` |
| **Event** | Webinars, conferences | `name`, `startDate`, `location` |
| **HowTo** | Tutorials, guides | `step`, `totalTime` |

Implement at least **one** of these on every page.

## 🛠️ Quick Implementation Checklist

- ✅ **Choose JSON‑LD** (recommended) or Microdata.
- ✅ **Validate** with Google Rich Results Test.
- ✅ **Add `@type`** matching the page purpose.
- ✅ **Include `url` and `image`** for visual SERP features.
- ✅ **Keep data up‑to‑date** – stale schema can cause manual penalties.
- ✅ **Monitor** via Search Console > Enhancements.
