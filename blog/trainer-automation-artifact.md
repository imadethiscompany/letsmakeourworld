# Trainer Automation Artifact

This is a minimal automation artifact for the **Trainer** product.

It demonstrates a simple Python script that could be used to automate trainer onboarding:

```python
def onboard_trainer(name: str, email: str):
    """Placeholder function for onboarding a new trainer."""
    print(f"Onboarding trainer {name} with email {email}")

# Example usage
if __name__ == "__main__":
    onboard_trainer("Alice", "alice@example.com")
```

Deploy this artifact as part of the Trainer product suite.
