### How It Works (3 Simple Steps)
1. **Send a request** – POST JSON with the data you want to verify.
2. **Proof AI analyzes** – Our models compare against global datasets.
3. **Receive results** – Confidence score, flags, and suggested actions.

```bash
curl -X POST https://api.proofapi.com/v1/verify \
  -H "Authorization: Bearer YOUR_KEY" \
  -d '{"email":"test@example.com","phone":"+14155552671"}'
```
