## What Are AI Coding Agents?
AI Coding Agents are autonomous, task‑focused assistants that write, refactor, and debug code for you. Powered by large language models and integrated with your IDE, they act like a junior developer on demand—handling repetitive chores, generating boilerplate, and even suggesting architectural improvements.

## How It Works (3‑Step Process)
1. **Define the Task** – Write a concise prompt, e.g., *"Create a CRUD API for a Todo app using FastAPI"*.
2. **Agent Generates Code** – The AI produces fully functional, typed code with tests.
3. **Review & Iterate** – Accept, edit, or ask for refinements instantly.

## Comparison: AI Coding Agents vs Traditional Tools
- **Static Code Completion (e.g., Copilot)** – Offers line‑by‑line suggestions.
- **AI Coding Agents** – Execute end‑to‑end tasks, manage state, and iterate until the goal is met.
