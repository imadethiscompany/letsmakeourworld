### Seamless Integration
```bash
# Install the SDK
pip install enterprise-ai-toolkit

# Quick start – call Anthropic or OpenAI
from enterprise_ai_toolkit import AIClient
client = AIClient(api_key='YOUR_KEY')
response = client.generate(model='anthropic.claude-v2', prompt='Summarize the quarterly report')
print(response)
```

*Supports OpenAI (`gpt-4`, `gpt-3.5-turbo`) and Anthropic (`claude-v1`, `claude-v2`) out of the box.*
